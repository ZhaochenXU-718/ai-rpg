# AIRPG 引擎与内容修改守则

初版：2026-07-10
最近修订：2026-07-15，叙事优先批次 C

## 1. 先分类，再改代码

遇到体验问题先问：

1. 这是文字表达问题，还是世界事实问题？
2. 换一个故事仍会发生吗？

由此分三类：

- **A｜生成/表现问题**：同一事实写得生硬、人物语气不对、节奏平。改 prompt、人物卡、记忆或模型策略，不新增机械规则。
- **B｜内容问题**：具体故事的地点不连通、人物动机矛盾、锚点条件不可达。改 YAML；若是一类常见错误，给校验器加规则。
- **C｜协议问题**：未提交事实被当真、主体秘密泄漏、撤回后旧结果仍能提交。才允许修改引擎核心，并必须落为故事无关的协议。

LLM 能把矛盾说圆，不代表矛盾消失。事实缺失、归属冲突和秘密泄漏永远不是 A 类。

## 2. 七条守则

1. **作者立法，模型创作，引擎守账。** 不把人物扮演工程化成数值，也不把铁律交给 prompt。
2. **引擎不认识故事专名。** 代码只认识 entity、location、fact、boundary、anchor 和 revision。
3. **Storylet 是事实订阅者。** 禁止恢复普通行动白名单或用锚点路由自由输入。
4. **只机械化铁律。** 位置、关键物品、披露、承诺、锚点、不可逆事件与世界边界需要代码；关系冷暖和普通环境细节进入叙事记忆。
5. **感知按主体隔离。** 每个 prompt 只接收一个明确 audience/subject 的快照；不能为了方便把完整 state 交给模型再要求它“别看”。
6. **提交必须原子且可撤回。** 生成结果先在工作副本检查，失败零变化；成功后才增长 revision 和 checkpoint。
7. **CLI 是可审计脚手架。** 它应忠实展示当前能力边界，不假装 Phase 2 已实现，也不演化成手写自然语言解析器。

## 3. 当前架构边界

- **PerceptionSnapshot**：玩家/NPC/Director 共用形状、不同披露策略；没有 capability 菜单。
- **SuggestedAction**：可编辑散文灵感，没有执行权限。
- **Narrative / DirectorPlan / NpcTurn**：模型提议，均不是真相。
- **FactBatch**：事实抽取后的唯一提交入口；必须绑定当前 revision。
- **IronLawViolation**：代码级冲突结果，驱动有限重生成。
- **Local Canon**：作者预授权的生成地点/局势，独立准入。
- **事实锚点**：提交后扫描，兑现作者关键因果。
- **状态时间线**：checkpoint、撤回和保留分支。

Phase 1 已完成协议和提交缝。Phase 2 前，CLI 普通回合只提交散文与已声明锚点，不写移动、物品、披露或承诺。

## 4. 修改决策表

| 症状 | 应改层 | 例子 |
|---|---|---|
| 人物说话不像自己 | 人物卡 / NPC prompt | 补 `voice` 与私有记忆，不加“说服值” |
| 模型写出远处人物的秘密 | 感知协议 | 检查 subject snapshot，而不是追加一句“不要泄漏” |
| 叙事声称拿到仍由 NPC 持有的物品 | 事实抽取 / 铁律检查 | 返回 item_custody 冲突并重生成 |
| 某个锚点永远不可达 | 内容 + 校验/场景回归 | 修条件或前置事实；不要为该故事写引擎特判 |
| Director 让陌生人物进场 | Director 复验 | actor 必须来自作者人物池并有权威位置 |
| NPC 对已撤回事件仍有记忆 | 时间线 / 记忆协议 | 记忆索引必须跟随 checkpoint 分支 |
| 所有故事都需要新的硬核资源 | 可选铁律扩展 | 以通用扩展点加入，不污染默认循环 |

## 5. 从 pre-pivot 试玩保留的教训

以下结论继续有效，但解决方式已经改变：

- 玩家看不到的对象不能出现在 prompt 或 UI；
- 人物和物品位置必须有唯一权威源；
- 无效/冲突生成不能消耗回合；
- 结果来源必须可审计，不能把世界节拍写成玩家成功；
- 故事词汇必须来自内容；
- 关键路线需要回归，但不能再用 intent/object walkthrough 模拟。

历史机械方案与转向理由保留在 `dev-notes/` 和 `dev-notes-v2/2026-07-14.md`，不再作为当前实现说明。

## 6. 新模块准入问题

新增模块前必须回答：

1. 它保护的是铁律，还是只让一种故事更像游戏规则？
2. 能否通过作者内容、记忆或 provider 策略解决？
3. 换三个不同类型的故事，这个概念仍成立吗？
4. 它会不会重新要求作者枚举普通行动？
5. 失败时是否零状态变化、可解释、可重试？
6. 是否有主体感知、revision、trace 和分支语义？

有任一项答不清，不进入核心。
