# AIRPG 行动提案

`ideas` 根据当前玩家感知生成最多五张自然语言提案，`idea <编号>` 采用其中一张。玩家可以完全忽略或改写它们。

提案只有标题、行动文本、侧重点和理由。它不携带能力、计划、预期状态变化、校验结果或执行权限。

提案必须绑定当前 `state_revision`。玩家完成其他回合或撤回后，旧提案失效。M3 会提供与旁白相同的裁剪后软记忆，用于延续开放事项和避免重复已解决内容；当前感知仍有更高优先级，记忆中的远处人物不会变成当前可行动对象。provider 返回的越界提案仍会被过滤。

provider 不可用时，引擎会从当前可见人物、环境和出口生成少量通用灵感。fallback 仍只是文本，不会绕过后验物理事实管线。
