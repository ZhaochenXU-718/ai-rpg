# 2026-07-17｜P0：让作者意图进入叙事闭环

## 背景

[Creator's Guides 能力分析](../docs/isekaizero-creators-guides-capability-analysis.md)确认了当前最大断层：schema 强制作者填写 `motivation`、`voice`、`initial_relationship`，但这些字段只进 `audience=NPC` 的 `subject_context`，而当前没有自动 NPC 回合——作者字段通过校验却不参与主要生成。`premise` 只用于开场渲染，`private_goal` 在运行时完全无消费方。

## 本批次落地

### 内容 schema：作者叙事分层

- 新增可选顶层字段：`player_facing_summary`（只给玩家）、`emotional_contract`、`ai_plot`（五个固定键，含 `hidden_truth`）、`narrative_guidelines`、`critical_reminders`（最多 4 条）；
- 人物卡新增可选：`secret`（正式校验）、`pressure`、`behavior`、`mannerisms`、`narration_notes`、`dialogue_examples`；
- `ai_plot` 键名封闭：拼错 `hidden_truth` 会被校验器拒绝，防止本应保密的内容因笔误流入提案。

### NarrativeAuthorContext：旁白专用作者通道

- 新增与 `PerceptionSnapshot` 分离的 `NarrativeAuthorContext`（`story_brief` / `emotional_contract` / `active_guidelines` / `critical_reminders` / `in_scene_character_cards`）；
- `narration` 每回合按当前可见人物编译在场人物完整私有卡，随 `NarrativeRequest` 交给旁白，并记入 trace；
- 旁白系统 prompt 从"不使用未披露私密信息"改为"知道但不得说破"：秘密可以驱动回避、迟疑和撒谎，但玩家未探明前不得写成已知事实；`critical_reminders` 声明为最高优先级；
- prompt 版本：narrate v6→v7，suggestions v3→v4。

### ideas：脱敏故事方向

- 提案请求新增 `story_direction`：`ai_plot` 去掉 `hidden_truth`，加 `emotional_contract`；
- 人物卡私有字段（含 `pressure`）刻意不进提案：卡片文本原样展示给玩家，没有披露守卫——这是对分析文档 P0 第 4 条"当前压力"的一处有意收窄，等真实试玩证明提案确实缺方向再放开；
- 既有隐藏实体过滤器继续兜底：脱敏蓝图若提到玩家未见过的作者实体，引用它们的草稿仍被丢弃。

### prompt 快照测试

新增 `tests/test_prompt_routing.py`，用夹具中每层唯一的哨兵串断言路由：

| 作者层 | 旁白 | 提案 | 玩家感知 | 事实抽取 |
|---|---|---|---|---|
| `ai_plot`（含 hidden_truth） | ✓ | 去 hidden_truth | ✗ | ✗ |
| `emotional_contract` | ✓ | ✓ | ✗ | ✗ |
| guidelines / reminders | ✓ | ✗ | ✗ | ✗ |
| 在场人物私有卡 | ✓ | ✗ | ✗ | ✗ |
| `player_facing_summary` | ✗ | ✗ | ✗ | ✗ |

这类"字段进入了哪个调用"的断言正是 `private_goal` 空转问题应有的验收工具。

## 边界不变

- 权威状态仍只有 `positions` 与 `item_locations`，本批次零状态扩张；
- 没有前验行动路由，没有模块/编排器（P1），没有机械裁判（P2）；
- 作者上下文是纯 prompt 材料，不携带任何 patch 权限。

## 验收

- 全量离线测试通过（104 passed，含 12 个新快照/校验测试）；
- `open_neighbor_scene` 夹具补齐全部新字段并通过校验器；两个 `pre_pivot_archive` 归档不受影响；
- 文档同步：README、content-schema、authoring-contract、action-suggestions、narrative-first-protocol、engine-principles。

## 下一步（P1 预告）

按能力分析 §5 P1：可选 `modules` + 代码层模块编排器（非 LLM 调用），软记忆记录 `offered/engaged/resolved/dropped`；随后创作一个情绪目标明确、能跑 25—40 回合的正式试玩故事，观察人物漂移、秘密泄漏与钩子重复。旧式 Director 不恢复；只有试玩证明旁白单次调用守不住长线方向时，才考虑低频、小输出、无状态权限的导演评估调用。
