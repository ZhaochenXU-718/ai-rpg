# 开发记录（叙事优先时代）

这个目录记录 AIRPG 自 2026-07-14 叙事优先转向（`pivot/narrative-first` 分支）之后的思考、决策、计划和实现情况。pre-pivot 时期（前验路由架构）的记录保留在 [dev-notes/](../dev-notes/)，作为历史不再追加。

## 记录约定

沿用旧目录的约定：

- 文件名使用 `YYYY-MM-DD.md`；同一天的内容持续追加，不重复创建。
- 重点记录问题、判断依据、最终结论和实际实现，不写流水账。
- "下一步"保持在 2–4 项，每项对应一个可验收的阶段。
- 已改变的架构决定要说明原因；尚未验证的想法要明确标记为假设。

本时代新增两条：

- **拆除与新建分开记录**：删老代码的批次必须单独说明"删了什么、为什么现在可以删、哪些测试随之退役"，不与新功能混在一批。
- **prompt 规则不算控制**：任何"靠 prompt 约束模型"的措施记录为缓解而非解决；只有代码级校验才能标记问题为已解决（试玩已两次证明 prompt 规则会被违反）。

## 建议结构

# YYYY-MM-DD 开发记录

## 今日主题

## 实现情况
